# Spiking-FullSubNet 기반 노이즈 캔슬링 처리 순서 (매우 상세 버전)

이 문서는 Spiking-FullSubNet 논문에서 제안한 신경망 기반 노이즈 캔슬링(Speech Enhancement) 파이프라인을 **입력 신호 수준부터 학습까지** 한 번에 이해할 수 있도록 단계별로 정리한 것입니다.

---

## 1. 신호 모델과 목표 정의

### 1.1 기본 신호 모델

마이크로 들어오는 실제 신호는 다음처럼 표현합니다.

- x(t) = s(t) + u(t)
  - x(t): 실제로 녹음된 신호 (noisy signal)
  - s(t): 원하는 깨끗한 음성 (clean speech)
  - u(t): 제거 대상인 잡음 (noise)

Spiking-FullSubNet의 **최종 목표**는, 입력 x(t)로부터 s(t)에 최대한 가까운 추정치 ŝ(t)를 만들어 내는 것입니다.

즉, 이 알고리즘이 하는 일은

- "노이즈를 없앤다"라기보다는
- "노이즈가 섞인 신호에서 **음성 성분만 뽑아서 복원**한다"에 가깝습니다.

### 1.2 왜 시간 도메인 그대로 처리하지 않을까?

시간 도메인 파형은 "언제, 어떤 주파수의 성분이 얼마나 있는지"를 직관적으로 보기 어렵습니다.

- 사람 목소리는 특정 주파수 대역에 강하게 나타나고
- 자음/모음에 따라 시간적으로 빠르게 변합니다.

이 패턴을 잘 보기 위해서는 **시간(Time)과 주파수(Frequency)를 동시에 보는 표현**, 즉 **TF(Time-Frequency) 도메인**이 필요합니다. 그래서 STFT를 사용합니다.

---

## 2. STFT: 시간→TF 도메인 변환

### 2.1 STFT 개념

STFT(Short-Time Fourier Transform)는 긴 신호를 짧은 구간(window)으로 잘라서, 각 구간마다 FFT를 적용하는 변환입니다.

결과물은 2차원 행렬:

- 가로축: 시간 프레임 index (n = 0, 1, 2, ...)
- 세로축: 주파수 bin index (f = 0, 1, ..., F-1)
- 값: 특정 시간 n, 특정 주파수 f에서의 **복소수 스펙트럼 값** X(n,f)

이걸 숫자 예시로 보면 대략 이렇게 생각할 수 있습니다.

        100Hz  500Hz  1kHz  3kHz  8kHz
 t=0.0  [ 0.1   0.8   0.3   0.1   0.05 ]
 t=0.1  [ 0.2   0.9   0.7   0.6   0.02 ]
 t=0.2  [ 0.1   0.2   0.1   0.05  0.01 ]

여기서 **각 칸 하나가 바로 bin**입니다.

- "t=0.1초, 1kHz bin의 값 = 0.7" 처럼 해석합니다.

### 2.2 이 논문에서 쓰는 설정(대표 예)

논문 및 구현에서는 대략 다음과 같은 설정을 사용합니다.

- 샘플레이트: 16kHz 가정
- 윈도우 크기: 32ms (약 512 샘플)
- hop length: 8ms
- FFT 크기: 512
- 윈도우 함수: Hanning window

이 설정으로 STFT를 하면, 시간–주파수 격자 X(n,f)가 생성되고, 알고리즘은 이 격자 위에서 작업을 합니다.

주의할 점:
- X(n,f)는 **복소수**입니다 (크기 + 위상).
- 모델은 주로 **크기(|X|)**를 입력으로 사용하고, 위상은 나중에 복원할 때 쓰거나, 복소 필터 방식으로 같이 다룹니다.

## 3. Full-Band 경로: 전체 스펙트럼 컨텍스트 추출

### 3.1 Full-Band의 의미

Full-Band 경로는 말 그대로 **전체 주파수 대역을 한 번에 보는 경로**입니다.

- 입력: 전체 주파수에 대한 magnitude 스펙트럼 |X(n,f)|
- 출력: 각 (n,f)에 대해 "글로벌 문맥"을 담은 임베딩 E(n,f)

여기서 "글로벌"이라는 말은

- 이 시간 프레임에서
- 전체 주파수에 어떤 패턴이 깔려 있는지

를 의미합니다.

예를 들면:
- 전체적으로 저주파가 강하면 → 비행기 엔진/에어컨류 소음일 가능성이 크다
- 중고역에 고르게 에너지가 퍼져 있으면 → 카페 잡음 + 사람 말소리가 섞인 상황일 수 있다

이런 큰 그림 정보를 학습적으로 뽑아내는 것이 Full-Band 경로의 역할입니다.

### 3.2 Full-Band 내부 구조 (GSN 스택)

Full-Band 경로는 여러 층의 **GSN(Gated Spiking Neuron)** 레이어로 구성됩니다.

- 시간 축을 따라 입력을 흘려보내면서
- 스파이킹 뉴런 특성(이벤트 기반)으로 시간 정보를 처리하고
- 각 (n,f)에 대해 컨텍스트가 반영된 특징 E(n,f)를 출력합니다.

이 E(n,f)는 나중에 Sub-Band 경로에서 함께 사용됩니다. 즉, **로컬 처리에 글로벌 정보를 끼얹어 주는 역할**입니다.

---

## 4. Frequency Partitioning: 주파수 대역 나누기

### 4.1 왜 나누는가?

모든 주파수 bin을 똑같이 세밀하게 처리하면

- 파라미터 수↑
- 연산량↑
- 전력 소모↑

반면, 인간의 청각 시스템은

- 저주파에 더 민감(정밀하게 구분)
- 고주파는 비교적 거칠게 구분

합니다.

논문은 이 점을 활용해서 **주파수 축을 파티션(구간)으로 나누고**, 각 파티션마다 처리 granularity를 다르게 둡니다.

### 4.2 파티션과 granularity

예시적으로:

- P1: 0~500Hz (저주파)
- P2: 500Hz~2kHz (중간)
- P3: 2kHz~8kHz (고주파)

각 P_k마다 granularity g_k를 두어,

- 저주파 파티션: g_k를 작게 → 더 많은 bin을 세밀하게
- 고주파 파티션: g_k를 크게 → 여러 bin을 묶어 처리

이렇게 하면, **인지적으로 중요한 구간(저주파 음성 영역)을 더 정밀하게**, 그렇지 않은 구간은 더 효율적으로 처리할 수 있습니다.

---

## 5. Sub-Band 경로: 로컬 패턴 + 글로벌 컨텍스트

### 5.1 Sub-Band의 목표

Sub-Band 경로는 각 파티션 P_k 안에서 **세밀한 패턴**을 보는 역할을 합니다.

궁극적으로 알고 싶은 것:

- "이 시간–주파수 위치(혹은 그룹)가 **음성 위주인가, 노이즈 위주인가**?"

각 위치마다 이 판단을 잘하면, 나중에 **마스크**를 통해 노이즈만 억제하고 음성은 살릴 수 있습니다.

### 5.2 Sub-Band 입력 특징 설계

Sub-Band 경로에서 하나의 위치를 볼 때 사용하는 정보는 대략 다음과 같습니다.

1. 현재 주파수(또는 주파수 그룹)의 noisy magnitude
2. 그 주변 ±N개의 이웃 주파수 bin 값 (로컬 주파수 컨텍스트)
3. 몇 개 이전/이후 시간 프레임 값 (로컬 시간 컨텍스트)
4. Full-Band 경로에서 온 글로벌 embedding E(n,f)

즉, 하나의 위치를 볼 때도:

- 인접 주파수에서 어떤 패턴이 이어지는지
- 시간적으로 어떤 변화가 있는지
- 전체 스펙트럼 관점에서 이 위치가 어떤 상황인지

를 **한 번에 고려**합니다.

### 5.3 EQ/전통 ANC와의 차이 (bin 단위 처리)

전통적인 EQ/ANC:

- "3kHz 대역 -10dB"처럼 **주파수 줄 단위**로 처리
- 시간에 관계없이 해당 주파수 전체가 깎임

Sub-Band 마스크 기반 방식:

- **시간 × 주파수 칸(bin) 단위**로 처리
- 같은 3kHz라도
  - 사람이 말하는 순간의 3kHz bin: 보존 (마스크≈1)
  - 사람이 말하지 않고 노이즈만 있는 순간의 3kHz bin: 제거 (마스크≈0)

=> 같은 주파수 대역이라도, **시간에 따라 다르게 처리할 수 있다는 것**이 핵심적인 차이입니다.

## 6. GSN(Gated Spiking Neuron)으로 시간 정보 처리

### 6.1 기존 SNN(LIF)의 한계

기존의 LIF(Leaky Integrate-and-Fire) 뉴런은

- 누적된 막전위를 일정 비율로 줄여가는 decay rate λ가 **고정값**입니다.

문제는 실제 오디오 신호가

- 어떤 구간은 느리게 변하고
- 어떤 구간은 매우 빠르게 변하는 등

시간 스케일이 계속 바뀐다는 점입니다.

고정된 λ로는 다양한 시간 스케일에 모두 잘 대응하기 어렵습니다.

### 6.2 GSN의 아이디어

GSN은 decay rate를 **입력에 따라 동적으로 조절**합니다.

- 특정 상황에서는 과거 정보를 오래 유지 (느리게 잊음)
- 또 다른 상황에서는 과거를 빨리 잊고 현재 입력에 반응 (빠르게 잊음)

이는 RNN/LSTM의 forget gate와 개념적으로 유사합니다.

### 6.3 왜 이게 노이즈 캔슬링에 중요하나?

- 노이즈는 대체로 천천히, 비슷한 패턴으로 계속 발생 (stationary 성향)
- 음성은 자음/모음, 단어 경계 등으로 인해 빠르게 변화 (non-stationary)

GSN은 이런 시간적 패턴 차이를 더 잘 포착할 수 있어서,

- "여기는 그냥 계속 깔리는 노이즈"
- "여기는 갑자기 생긴 음성 변화"

를 구분하는 데 유리합니다.

또한 SNN 특성 덕분에, 뉴로모픽 칩에서는 필요한 순간에만 연산이 일어나 **전력 소모가 매우 낮아질 수 있다**는 장점이 있습니다.

## 7. 출력: 마스크 및 복합 필터 추정

### 7.1 마스크(Mask) 기반 접근

딥러닝 기반 Speech Enhancement의 대표적인 방식은 **TF 마스크 추정**입니다.

- M(n,f) ∈ [0,1]
  - 1에 가까울수록: "이 bin에는 음성이 많으니 살려라"
  - 0에 가까울수록: "이 bin에는 노이즈가 많으니 줄여라"

이때 clean 스펙트럼 추정치는 다음처럼 얻습니다.

- Ŝ(n,f) = M(n,f) · X(n,f)

즉, noisy 스펙트럼의 각 칸(bin)에 대해 **스케일을 조절**하는 방식입니다.

### 7.2 Complex MFDF(복소 멀티프레임 딥 필터링)

Spiking-FullSubNet은 단순 magnitude 마스크만 쓰지 않고, **복소수 필터**를 여러 프레임에 걸쳐 적용하는 방식(딥 필터링)을 사용합니다.

아이디어:

- 각 주파수(혹은 파티션) f에
- 현재 및 주변 시간 프레임들을 고려한 복소 필터 w̄_f^k(n)을 추정
- 이 필터를 X(n,f)에 곱해 Ŝ(n,f)를 생성

개념적으로는:

- Ŝ(n,f) = w̄_f^k(n) ⊙ X(n,f)

여기서 ⊙는 위치별 곱입니다.

복소 필터를 쓰는 이유는 **위상(phase) 정보까지 함께 보정**해서, 더 자연스러운 음질을 얻기 위함입니다.

### 7.3 주파수별 필터 길이 차별화

주파수 대역에 따라 필터 길이를 다르게 둡니다.

- 저주파: 더 긴 필터 (시간적으로 더 긴 구간을 보며 정교하게 처리)
- 고주파: 더 짧은 필터 (계산량 절약, 필요 충분 수준 처리)

이는 앞에서 말한 Frequency Partitioning 철학과 맞물려, 중요 구간에 더 많은 자원을 배분하는 전략입니다.

## 8. iSTFT: TF → 시간 도메인 복원

### 8.1 복소 스펙트럼에서 파형으로

필터링이 끝나면, 우리는 TF 도메인에서 **복원된 음성 스펙트럼** Ŝ(n,f)를 갖게 됩니다.

이제 이걸 다시 시간 도메인 파형 ŝ(t)로 바꾸기 위해 iSTFT(Inverse STFT)를 합니다.

- 각 프레임마다 inverse FFT 수행
- 앞에서 사용한 윈도우, hop length를 그대로 써서 overlap-add

이 과정을 거치면 **연속적인 시간 도메인 오디오 파형**이 나옵니다. 이것이 최종 출력 음성입니다.

### 8.2 레이턴시(지연)에 미치는 영향

- STFT 윈도우 크기가 32ms이기 때문에, 실시간 처리에서는 적어도 이 정도 규모의 지연이 발생합니다.
- 통화/회의/스트리밍과 같이 약간의 지연이 허용되는 환경에서는 사용 가능하지만,
- 헤드폰 ANC처럼 10ms 이하 지연이 요구되는 상황에서는 추가적인 구조 최적화가 필요합니다.

## 9. 학습: 이 파이프라인을 어떻게 학습시키는가?

### 9.1 데이터셋 구성 (입력/정답 쌍 만들기)

현실에서 똑같은 장면을

- 한 마이크에는 noisy,
- 다른 마이크에는 완전히 clean

형태로 동시에 녹음하는 것은 거의 불가능에 가깝습니다.

그래서 보통은 **clean과 noise를 따로 녹음한 후, 합성해서 학습 데이터를 만듭니다.**

1. Clean speech 데이터셋 준비
   - 예: LibriSpeech, VCTK, DNS Challenge의 clean speech 등
2. Noise 데이터셋 준비
   - 카페, 도로, 공장, 빗소리, 키보드, 바람, 군중 소음 등
3. 합성
   - noisy = clean + α × noise
   - α를 조절해서 SNR을 -5dB ~ 20dB 사이로 다양하게 만듦

이렇게 하면 **(입력: noisy, 정답: clean)** 쌍을 대량으로 만들 수 있습니다.

### 9.2 학습 시 입출력 관점에서 정리

- 입력: noisy 오디오 x(t)
  - → STFT → X(n,f)
- 모델: Full-Band + Sub-Band + GSN + MFDF 구조
  - → TF 도메인에서 마스크/필터를 추정해 Ŝ(n,f) 생성
- 출력: Ŝ(n,f)
  - → iSTFT → ŝ(t)
- 정답: clean 오디오 s(t)

학습 시에는 ŝ(t) 또는 Ŝ(n,f)와 s(t)/S(n,f)를 비교해 loss를 계산합니다.

### 9.3 Loss Function: 음성 보존 vs 노이즈 억제

단순히 "출력과 clean 사이의 MSE만 최소화"하면 문제가 생깁니다.

- 노이즈를 너무 많이 줄이려다 보면 → 음성 부분까지 같이 깎여서 답답한 소리
- 음성을 살리려고만 하면 → 노이즈가 많이 남아서 지저분한 소리

그래서 보통 Loss를 여러 요소로 나눠서 설계합니다.

대표적으로:

1. 음성 보존 Loss
   - clean에서 에너지가 큰 bin에서는 마스크가 1에 가깝도록 유도
2. 노이즈 억제 Loss
   - noise에서 에너지가 큰 bin에서는 마스크가 0에 가깝도록 유도
3. 지각적(Perceptual) Loss
   - PESQ, STOI 등 사람이 들었을 때의 품질과 연관된 척도를 반영

이렇게 다중 Loss를 쓰면, **음성 보존과 노이즈 억제 사이의 균형**을 잡을 수 있습니다.

### 9.4 일반화(Generalization)와 도전 과제

모델이 학습에서 본 것과 다른 새로운 노이즈(새로운 환경, 장비, 사람, 언어 등)에 대해서도 잘 작동해야 합니다.

이를 위해:

- 가능한 한 다양한 노이즈 유형을 섞어서 학습
- 다양한 SNR, 다양한 화자, 다양한 녹음 조건 포함
- Self-supervised / unsupervised 기법을 써서, clean 레이블이 없는 데이터에서도 추가 학습하는 연구도 활발히 진행 중

Intel DNS/Neuromorphic DNS Challenge도 바로 이런 **실제 환경에서의 일반화 성능**을 겨루는 대회입니다.

## 10. 전통 ANC와 이 알고리즘의 관계 정리

### 10.1 전통 ANC (헤드폰에 들어가는 것)

- 물리적인 음파를 **역위상으로 상쇄**하는 기술
- 외부 마이크 → 소음 파형 측정 → 역위상 파형 생성 → 스피커로 출력 → 공기 중에서 소음 상쇄
- 주로 저주파, 예측 가능한 소음에 강함 (비행기, 버스, 에어컨 등)

### 10.2 Spiking-FullSubNet

- 마이크로 들어온 **디지털 신호**에서 노이즈를 제거하는 알고리즘
- STFT를 통해 TF 도메인으로 변환 → 마스크/필터 추정 → iSTFT로 깨끗한 신호 복원
- 고주파, 불규칙 소음에서도 음성과 노이즈를 더 잘 분리
- SNN 구조를 이용해 **저전력 구현** 가능성이 핵심 포인트

### 10.3 "ANC로 쓸 수 있나?"에 대한 관점

이 알고리즘 자체는 **역위상 음파를 바로 만들어서 스피커로 쏘는 구조가 아니라**,

- "마이크 신호를 정제해서 **상대방에게 전달되는 소리**를 깨끗하게 만드는" 쪽에 가깝습니다.

다만,

- 뉴로모픽 SNN 기반이라 전력이 매우 낮기 때문에,
- 향후 이어폰/보청기 등의 온디바이스 노이즈 억제(특히 마이크 경로)에 활용할 수 있는 **기술적 토대**를 마련했다고 볼 수 있습니다.

## 11. 전체 처리 순서 한눈에 다시 보기

마지막으로, 지금까지 설명한 내용을 순서대로 한 줄씩 정리하면:

1. 마이크에서 noisy 신호 x(t)를 받는다 (s(t) + u(t)).
2. x(t)에 STFT를 적용해 TF 스펙트럼 X(n,f)를 얻는다.
3. Full-Band 경로가 전체 스펙트럼을 보고 글로벌 임베딩 E(n,f)를 만든다.
4. 주파수 축을 여러 파티션으로 나눈다 (Frequency Partitioning).
5. 각 파티션마다 Sub-Band 경로가 로컬 TF 패턴 + E(n,f)를 이용해 특징을 추출한다.
6. GSN 구조를 통해 시간적 상관관계와 다양한 시간 스케일 변화를 학습적으로 처리한다.
7. 각 TF 위치(혹은 파티션)에 대해 마스크/복소 필터를 추정한다.
8. 이 필터/마스크를 noisy 스펙트럼 X(n,f)에 곱해 복원 스펙트럼 Ŝ(n,f)를 얻는다.
9. Ŝ(n,f)에 iSTFT를 적용해 시간 도메인 신호 ŝ(t)를 복원한다.
10. ŝ(t)가 최종적으로 노이즈가 억제된 출력 음성이다.

이것이 Spiking-FullSubNet 기반 노이즈 캔슬링의 **세부 처리 순서 전체 그림**입니다.
